切换会断开现有连接，不会自动回滚。

TCP 模式会把 UDP 映射封装为 UDP over TCP，可能丢失 UDP 数据包。

端口策略

已运行的映射不会因移出白名单而关闭；新注册会立即使用新策略。

Web 管理员

管理器使用已保存的上游密码作为当前密码，并在保存后立即用新凭据重新登录。

当前上游密码不会显示，也不会提交到浏览器。

代理信任

仅当上游反向代理会覆盖 X-Forwarded-For / X-Real-IP 时启用。

如果代理不会覆盖这些请求头，启用后客户端可以伪造来源 IP，绕过登录限速。
